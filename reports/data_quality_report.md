## 4. Validation Rules

- MNIST: IDX magic numbers, data type code, header dimensions, exact file byte lengths, image/label count equality, label range, expected 28x28 geometry, split separation.
- IAM: official annotation hierarchy (forms → lines → words), writer identifiers, official writer-independent partition membership, writer disjointness across splits, missing images, invalid images, empty transcriptions, duplicate ids/content, unexpected dimensions and unusable samples.
- Invalid samples are recorded with `usable: false` and an issue list; none is silently removed.

## 5. Limitations

- IAM is absent in this environment; its real statistics cannot be reported without fabrication.
- Bounding-box level word segmentation is parsed but not used by the text-line baseline.
- Duplicate-content detection uses image SHA-256 and is therefore exact-byte only.
- No performance or accuracy figures are reported; no model has been trained.
